Incident Time Machine

Feed ITM the logs and traces from an outage and it reconstructs what happened: a timeline, a dependency graph, and a ranked list of probable root causes with evidence.

Every report below is generated by itm demo from a seeded simulated incident, so the true cause is known and the ranking can be checked against it. This page and the reports it links are fully static: no server, no network.

# Benchmark

How often ITM ranks the true root cause first, measured on seeded synthetic
incidents generated by this project's own simulator.

**Limitation, stated first.** The simulator is written by the same project that
does the analysis. These numbers describe how well the method recovers a cause
from *this* generator's behaviour; they are not a claim about real production
systems. Tuning used development seeds only; the evaluation ranges below are
frozen and were not used for tuning.
